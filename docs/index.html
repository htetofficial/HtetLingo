Built for Real Language Mastery

Everything you need to go from absolute beginner to conversational polyglot.

📚

Smart Spaced Repetition (SRS)

High-yield vocabulary categorized by JLPT, HSK, and CEFR. Never forget words with scientifically scheduled intervals (Again, Hard, Good, Easy).

✍️

Structured Grammar Guides

Demystify Japanese particles (は vs が), Chinese aspect markers (了), Thai politeness particles (ครับ/ค่ะ), and Burmese verb endings with side-by-side explanations.

🎯

Adaptive Quizzes & Exercises

Multiple choice questions, audio listening comprehension tests, and sentence rearrangers that adapt to your mastery score.

🎙️

Native Pronunciation & Listening

Web Speech Synthesis API with adjustable speed controls (0.75x slow mode) and microphone recognition for speaking practice.

📖

Multilingual Offline Dictionary

Instant multi-script search with phonetic transcriptions (IPA, Romaji, Pinyin), parts of speech, and bookmarking.

🤖

HtetAI Conversational Tutoring

Roleplay realistic scenarios (ordering at a cafe, airport check-in, job interviews) with instant grammar corrections and cultural etiquette tips.

Technical Foundation

Web-First, Offline-First, Cross-Platform

Engineered to run seamlessly across Web, Android Native, iPad, and Mac Native.

⚡ 100% Offline Learning

Powered by client-side IndexedDB and Service Worker caching. Continue flashcards, quizzes, and dictionary lookups on planes or without internet.

☁️ Supabase Cloud Sync

Row Level Security (RLS) encrypted database storing user streaks, XP, custom bookmarks, and study history with seamless cross-device synchronization.

📱 Native Platform Portability

Using standard web technologies, HtetLingo packages directly into native Android APK/AAB and iOS/iPadOS/macOS applications using Capacitor.
