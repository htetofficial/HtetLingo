Platform Documentation

HtetLingo is an ambitious, community-rooted multilingual learning, dictionary, translation, and AI tutoring platform founded by Htet. It bridges global communication across English, Burmese (မြန်မာ), Japanese (日本語), Chinese (中文), Thai (ภาษาไทย), French, German, and Korean.

Unlike legacy dictionary apps that merely display static word translations, HtetLingo is built around cognitive acquisition: Spaced Repetition (SRS), structured cross-cultural grammar guides, speech pronunciation feedback, and conversational AI tutoring.

2. Cross-Platform Architecture

HtetLingo uses a Web-first, Offline-first, Cross-platform architecture. The core application is engineered with modern web standards (Progressive Web App), designed to compile into native platforms without rewriting business logic:

  • Cloudflare Pages (Web): Global edge distribution with zero cold starts and fast load times.
  • Android Native (Capacitor): Wraps web components into an Android Studio Gradle project with native speech and offline storage access.
  • iPadOS & macOS Native (Capacitor / Mac Catalyst): Adapts layout dynamically to iPad multi-column split view and native desktop window controls.
# Capacitor Build Configuration for Android and iOS/macOS npx @capacitor/cli create npx cap add android npx cap add ios npx cap sync

3. Offline-First Storage Engine

Learners in regions with intermittent connectivity (such as Myanmar) can use HtetLingo with complete reliability.

The offline engine combines IndexedDB for user learning data (SRS intervals, mastery scores, bookmarked terms, quiz history) with a Service Worker for asset caching. Even when completely disconnected, all flashcard sessions, grammar lessons, and dictionaries function without degradation.

4. Supabase Backend & RLS

Cloud synchronization and authentication are powered by Supabase. Every database table enforces Row Level Security (RLS) so users can only access their own learning progress.

-- Schema excerpt: Row Level Security for Profiles & Progress ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY; ALTER TABLE public.user_progress ENABLE ROW LEVEL SECURITY; CREATE POLICY "Users access own profile" ON public.profiles FOR ALL USING (auth.uid() = id); CREATE POLICY "Users access own learning progress" ON public.user_progress FOR ALL USING (auth.uid() = user_id);

6. Open-Source Datasets Roadmap

To expand the vocabulary database to hundreds of thousands of words, HtetLingo is designed to seamlessly integrate with prominent open-source lexical projects:

  • Tatoeba Project: Large-scale open collaborative database of contextual sentence pairs with translations in Burmese, English, Japanese, Chinese, and Thai.
  • JMdict & Kanjidic (EDRDG): The gold standard open-source Japanese-English electronic dictionary files.
  • CC-CEDICT: Comprehensive open Chinese-to-English dictionary database with Pinyin and character variants.
  • SEAlang Library & OpenBurmese: Authentic Southeast Asian linguistic resources for Burmese and Thai phonetic mappings.
  • Wiktionary Dumps: Open multilingual lexical database with pronunciations and etymology.
