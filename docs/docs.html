Platform Documentation

HtetLingo is a cute, feminist multilingual learning, dictionary, and AI tutoring platform founded by Htet. It bridges global communication across English, Burmese (မြန်မာ), Japanese (日本語), Chinese (中文), Thai (ภาษาไทย), French, German, and Korean.

The platform centers women, girls, and marginalized voices: emphasizing assertive communication, sisterhood, self-love, and personal safety. Rather than passive rote memorization, HtetLingo equips learners to speak with conviction, navigate the world independently, and connect deeply across cultures.

2. Open Source Lexical Datasets Integrated

HtetLingo integrates and cross-references a rich ecosystem of open source dictionary databases, wordlists, and linguistic resources:

1. EngMyanDictionary (soeminnminn/EngMyanDictionary-MAC):
Complete SQLite database containing 21,984 English-Myanmar dictionary entries with definitions, phonetics, and usage examples.
2. English-to-English Dictionaries (adityasahu252 & LexiVerse):
Comprehensive English monolingual lexicon with over 49,537 detailed word definitions.
3. Myanmar Female Names & Bilingual Mappings (L16H7 & MgHla):
Curated list of 2,304 Myanmar female names with cultural meanings, paired with 12,044 English-Myanmar name transliterations.
4. Myanmar Words & Segmentation (myanmartools, lwinmoe, trhura):
Over 41,343 segmented Burmese words and 28,854 common lexical items for spellchecking and syllable breaking.
5. Regional & Specialized Collections (Awesome Myanmar Wordlists):
Myanmar-Karen wordlists, Myanmar calendar (mmcal), postal codes, and HuggingFace Myanmar NLP models (nara-mini-v1).

3. Cross-Platform Architecture

HtetLingo is built with a Web-first, Offline-first, Cross-platform architecture:

  • Cloudflare Pages (Web): Global edge distribution hosting the Progressive Web App at htetlingo.pages.dev.
  • Android Native (Capacitor): Wraps web components into a native Android APK/AAB with native speech synthesis and persistent offline storage.
  • iPadOS & macOS Native: Fluid multi-column tablet and desktop layout supporting Apple Silicon.
# Capacitor Build Configuration for Android and iOS/macOS npx @capacitor/cli create npx cap add android npx cap add ios npx cap sync

4. Offline-First Storage Engine

Learners in regions with intermittent connectivity (such as Myanmar) can use HtetLingo with complete reliability.

The offline engine combines IndexedDB for user learning data (SRS intervals, mastery scores, bookmarked terms, quiz history) with a Service Worker for asset caching. Even when completely disconnected, all flashcard sessions, grammar lessons, and dictionaries function without degradation.

5. Supabase Backend & RLS

Cloud synchronization and authentication are powered by Supabase. Every database table enforces Row Level Security (RLS) so users can only access their own learning progress.

-- Schema excerpt: Row Level Security for Profiles & Progress ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY; ALTER TABLE public.user_progress ENABLE ROW LEVEL SECURITY; CREATE POLICY "Users access own profile" ON public.profiles FOR ALL USING (auth.uid() = id); CREATE POLICY "Users access own learning progress" ON public.user_progress FOR ALL USING (auth.uid() = user_id);
